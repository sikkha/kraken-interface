# Product Vision

The product should feel like a focused AI-assisted trading workstation rather than a generic chatbot or a loose collection of scripts.

Core experience goals:

- A serious operator console with market awareness, system state, and AI assistance visible at the same time.
- Clean backend seams so market data, strategy logic, AI interaction, and execution access can evolve independently.
- Incremental build-out around the existing Kraken CLI validation instead of a wholesale rewrite.
- Fast extension by future coding agents through readable folders, typed contracts, and concise project memory.
